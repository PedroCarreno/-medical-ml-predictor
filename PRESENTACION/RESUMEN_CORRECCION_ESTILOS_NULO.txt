PROBLEMA IDENTIFICADO:
---------------------
Al agregar .fillna('NULO') para convertir valores NaN en el string "NULO",
las funciones de estilo que detectaban pd.isna() dejaron de funcionar porque
ahora los valores son strings "NULO" en lugar de NaN.

SOLUCIÓN IMPLEMENTADA:
---------------------
Se modificaron las funciones de estilo para detectar TANTO valores NaN COMO
el string "NULO", asegurando que el formato visual se mantenga correctamente.

================================================================================
CELDAS MODIFICADAS
================================================================================

CELDA 7: highlight_nulls_red()
------------------------------
Propósito: Resaltar valores NULO en ROJO en el dataset original

ANTES:
    def highlight_nulls_red(val):
        """Highlight NULO values in red"""
        if pd.isna(val):
            return 'background-color: #ffcccc; color: #cc0000; font-weight: bold'
        return ''

DESPUÉS:
    def highlight_nulls_red(val):
        """Highlight NULO values in red"""
        if pd.isna(val) or val == 'NULO':
            return 'background-color: #ffcccc; color: #cc0000; font-weight: bold'
        return ''

Cambio: Se agregó "or val == 'NULO'" para detectar el string NULO


CELDA 22: highlight_filled_values()
-----------------------------------
Propósito: Resaltar en VERDE valores que fueron rellenados en el dataset limpio

ANTES:
    if pd.isna(orig_val) and pd.notna(current_val):
        styles.append('background-color: #ccffcc; color: #006600; font-weight: bold')

DESPUÉS:
    if (pd.isna(orig_val) or orig_val == 'NULO') and (pd.notna(current_val) and current_val != 'NULO'):
        styles.append('background-color: #ccffcc; color: #006600; font-weight: bold')

Cambio:
  - Agregado "or orig_val == 'NULO'" para detectar valores NULO originales
  - Agregado "and current_val != 'NULO'" para asegurar que el valor fue realmente rellenado


CELDA 22: Sección de estadísticas
---------------------------------
Propósito: Contar correctamente cuántos valores fueron rellenados

ANTES:
    if pd.isna(df_orig_for_compare.loc[idx, col]) and pd.notna(df_clean_display.loc[idx, col]):

DESPUÉS:
    orig_value = df_orig_for_compare.loc[idx, col]
